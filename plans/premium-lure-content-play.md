# Premium Lure Content Play — Adventure Wales

**Purpose:** Define exactly how we create high-conversion premium pages that act as sales assets for outbound email outreach.

## 1. The Lure Concept

Instead of asking operators to "claim a basic listing", we show them a **finished, beautiful, ready-to-go premium page** that already exists with their name on it. The email becomes:

> "We've built your full profile on Adventure Wales. Here's what it looks like. Would you like to activate it?"

This creates instant value and FOMO.

## 2. Premium Lure Page Requirements

Every lure page must meet these standards:

### Visual
- Minimum 6–8 high-quality, relevant photos
- Hero image that actually represents the experience
- Professional logo treatment where possible
- Clean, modern layout consistent with site design

### Copy
- 400–600 word benefit-focused description
- 2–3 real offers or packages highlighted
- Local context and insider tips
- Clear "why book with us" section
- Strong call-to-action language

### Platform Integration
- Added to 1–2 relevant itineraries
- Proper activity tags and region associations
- Structured data / schema ready
- Placeholder for reviews and analytics (even if zero)

### Trust Signals
- "Featured on Adventure Wales" framing
- Any accreditations or awards
- Contact/booking CTA (even if not yet live)

## 3. Target Selection Criteria (Who Gets a Lure Page)

Priority order for building lure pages:

1. High-intent activity types with good volume (coasteering, MTB, surfing, canyoning)
2. Operators in popular regions (Snowdonia, Pembrokeshire, Brecon Beacons)
3. Businesses with existing online presence (easier to research good imagery/copy)
4. Operators who already appear in our seed data but only have stub listings

Avoid:
- Very small or hobby operators
- Businesses with poor online reputation

## 4. Content Production Process

1. **Research** — Use aw-deep-research + aw-attraction-research skills
2. **Image Sourcing** — Use aw-image-sourcer skill (strict quality bar)
3. **Writing** — Use aw-content-writer skill with lure-specific brief
4. **Assembly** — Build page in content system or as static preview
5. **Review** — Quick internal quality check
6. **Email** — Personalised outreach using the page as attachment/link

## 5. Email Lure Sequence (Initial)

**Subject line ideas:**
- "Your Adventure Wales profile is ready"
- "We've built this for [Operator Name]"
- "Want this live on Adventure Wales?"

**Body structure:**
- Personal context (why we chose them)
- Preview of the page
- Clear next step (activate / discuss / see full details)
- Soft urgency ("We're launching outreach to 30 operators this month")

## 6. Success Metrics

- Lure page → email open rate target: >40%
- Email → reply / meeting rate target: >15%
- Conversion to paid: track per batch

## 7. Big Player Exception Handling

Major operators get full premium treatment immediately (no lure needed). Their pages become traffic magnets. Once we have 5k–10k monthly visitors, we begin selling them additional marketing services on top of their free premium presence.
